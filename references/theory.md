## 四段闭环

```
①欲望                          ②计划                 ③执行              ④回顾
产生 → 筛选 → 询问确认 → 记录  → 排程/分解 → 触发执行 → 收尾 → 日/周/月回顾 → 回到计划
```

1. **欲望**：从自由表达、日记、聊天里抽出可独立执行的欲望；先筛选（应不应该 / 能不能够 / 值不值得），再给确认卡，最后按决定分三层记录。收集关注点五块：自我提升、任务规划、环境扫描、人际需求、思考与材料整理。
2. **计划**：日程安排五步（巡检 → 估算 → 选择 → 排序 → 指定触发 + 分配积分），排序含路线聚类与缓冲；项目分解在 SMART / WBS / K\*I / 6W3H / 资源缓冲 / 微化之上补 DoD、依赖与关键路径、里程碑、风险与 B 方案、粒度、学习目标、防刷分。
3. **执行**：开始前 30 秒准备；计时由用户在滴答 App 手动开；干扰打标签并记一句话原因；检查点问四件事；卡住走诊断树，输出一个诊断 + 一个最小动作 + 一个复查时间；收尾确认结果与善后。积分不在执行时手算。
4. **回顾**：每天一篇日回顾（总结 / 确认 / 谋划 / 积分 / 身份反馈 / 一个实验）；周回顾看四类对象、趋势、卡住的项目、下周三个结果 + 一个实验、容量检查；月回顾算完成率与金额，做规则审计与 PDCA。每周期只改一个变量；语气是数据 + 好奇，不责备。
