# 积分规则

理论：`时间管理.md` 的积分/回顾部分；实现规则以设计稿 §5 与 `scripts/lib/scoring.py`、`settle.py`、`report.py` 为准。

**数字只从命令输出取**：`score`、`settle`、`balance`、`report`、`monthly`。不要手算，也不要凭记忆报余额。

## 1. 任务分

标题**末尾** `$N` 是最终分（正则 `\s*\$(\d+(?:\.\d+)?)\s*$`）；正文中间出现的 `$` 不算。

```
基础分 = 优先级底分 × 规模系数
优先级底分：高(5) 3 / 中(3) 2 / 低(1) 1 / 其余(0、2、无) 0.5
规模系数：S（≤1 番茄）1 / M（2–3）1.5 / L（≥4）2
```

**预填用 `score --size`，不要手算**：

```bash
"$PY" scripts/gtd.py score --title '写周报' --priority 5 --size L   # → final_points 6（3 × 2）
"$PY" scripts/gtd.py score --title '写周报' --priority 5            # → final_points 3（--size 默认 S）
"$PY" scripts/gtd.py score --title '写周报 $4' --priority 5 --size L # → final_points 4（显式 $N 胜出）
```

输出里 `explicit_points` 是标题的 `$N`（没有就是 `null`），`effective_points` 是预填分
（有 `$N` 就是 `N`，否则 `优先级底分 × 规模系数`），`final_points` 再套超时折扣。
规模系数**只影响预填**：结算按 `task_effective_points`，没写 `$` 一律按优先级底分，不乘规模。

结算时的**有效分**（`task_effective_points`）：

| 情形 | 有效分 |
| --- | --- |
| 父任务（有子任务） | 忽略（即使写了 `$`） |
| 标题有 `$N` | `N` |
| 子任务但没 `$` | 0 |
| 重复任务（`repeatFlag`）且没 `$` | 不计分、不进分母 |
| 其他 | 优先级底分（不再乘规模） |

- AI 预填 = `优先级底分 × 规模系数`，写进标题末尾（如 `写周报 $6`）；写完后 `$N` 就是最终分。

- `$0` → 明确不计分。
- 拆分时把父任务价格分摊到子任务，总和不超过父价格；不翻倍。
- **存量任务不改标题**；只有新建/排程时 AI 才预填。

## 2. 超时折扣

```
逾期 = 有截止时间 且 completedTime > dueDate
结算分 = 有效分 × (主观逾期 且 非突破类 ? 0.5 : 1)
```

- 主观 / 客观由用户在结算时确认一次（`settle --late-subjective ID1,ID2`）。
- 标签 `突破` 不打折。
- 没确认的逾期：先不打折，日回顾记 `late_pending: true`，下次问。

示例：

| 任务 | 优先级 | 规模 | 标题 | 结算分 |
| --- | --- | --- | --- | --- |
| 改简历 | 高 | L | `改简历 $6` | 6 |
| 刷一套面试题 | 中 | M | `刷一套面试题 $3` | 3 |
| 取快递 | 低 | S | `取快递 $1` | 1 |
| 高优先级拖到截止后（主观） | 高 | M | `写周报 $4.5` | 2.25 |
| 突破任务超时 | 高 | L | `上线新版本 $6` + `突破` | 6 |

## 3. 习惯分

- `$N` 可出现在习惯名**任意位置**（正则 `\$(\d+(?:\.\d+)?)`），取第一个。
- 打卡才算；未打卡 0 分。
- 有 `$N` 且有 `goal`：`value >= goal` 全额；`0 < value < goal` 给 `$N × value/goal`，**四舍五入到 0.5**（`floor(x*2+0.5)/2`，0.25 进到 0.5）；`value = 0` 给 0。
- `goal = 1` 等价于「打卡即满分」。
- 没有 `$N` 的习惯默认 **0 分**，不擅自改名；用户以后加 `$N` 自动启用。
- 习惯分计入当日收入和完成率分子。

## 4. 同名任务与习惯去重

按去掉 `$N`、`%N`、前导 `@` 并压缩空白后的名字比较，**只算一次**：

- 任务有显式 `$` → 算任务，习惯记 0；
- 否则算习惯，任务记 0 且从计划里剔除（不进分母）。
- 去重只在习惯当天得分为正时发生；习惯没打卡（0 分）不影响任务计分。

## 5. 日账

```
计划任务 = 截止日或开始日落在当天，排除 积分消费，排除「重复且无显式 $」
计划总价 planned_total = Σ 计划任务有效分
分母 denominator = min(60, max(30, planned_total))
收入 earned_total = Σ 任务结算分 + Σ 习惯分
完成率 rate = round(min(1, earned_total / denominator), 3)
可花分 spendable = max(0, min(earned_total, 60) − reserve)     # reserve 默认 5
```

- **`spendable` 写在当天 frontmatter 里，含义是「次日」额度**（消费扣的是前一天的 `spendable`）。
  所以「今天能花多少」要读**前一天**的账本：`balance --date 今天` 会同时给出
  「今日可花（来自昨天）」与「明日可花（今天结算后）」；今天还没结算也能查。
- 次日兑换娱乐时间：1 分 = 2 分钟，单日最多 120 分钟；次日未用完作废，不跨天。
- 超过 60 的部分记入周账，但不增加当日可花分。
- 完成率封顶 100%，超过记「超额」，不额外发钱。

## 6. 周账

```
周收入 weekly_earned = 前一天周收入 + 当日收入
周可花 weekly_balance = max(0, min(360, weekly_earned) − weekly_spent)
```

- 周一强制把周赚 / 周花 / 待罚清零（`daily` 的 spendable 仍取周日那条）。
- 1 分 = 1 分钟，周末最多 6 小时；周末结束清零。
- 日账与周账互不抵扣；同一笔得分同时进入两本账。

## 7. 消费（`积分消费` 标签）

- 打 `积分消费` 的任务是支出，**不计收入**，标题 `$` 也不参与收入。
- 支出分钟数 = 该任务所有专注记录时长之和（`focus`）；**没有专注记录**才退回读标题 `$N`（此时 `$N` 表示花费的分数，不是分钟）。
- 扣法：
  - 工作日：分钟 ÷ `day_rate`（2），只扣日账（前一天的 `spendable`）；不够就记 `unmet_minutes` / `unmet_points`，不扣成负数。
  - 双休：先扣日账（分钟 ÷ 2），不够再扣周账（剩余分钟 ÷ `week_rate` = 1）。
- 工作日只能花前一天的日账；日账不够不能动周账，只能少花或把消费任务挪到周末。

## 8. 惩罚与折扣

- **触发**：config 的 `penalty_habit` 那个习惯当天值 ≥ 1 → 当日可花分 ÷ 3；周末周账 ÷ 3；当月金额 ÷ 3（当月只扣一次）。脚本只认这一条通路，没有「手动标记触发」的入口。
- 有地板 0，不扣成负数。
- 区分「恣意放纵」（扣）与「身不由己」（迁移到下一个周期，不取消）。
- **复发协议**：触发后 24 小时内不追责，只记录触发情境 + 做一次替代行为。
- 重复任务：无显式 `$` 不计分、不进分母，只当提醒；有 `$` 才按任务计分。

## 9. 月账

```
工作日完成率 = 各工作日 rate 的平均
双休完成率   = 每个双休（周六+周日一组）min(1, 收入 / min(60, max(30, 计划合计))) 的平均
总完成率     = 两侧都有数据 ? avg(工作日完成率, 双休完成率) : 有数据的那一侧
金额         = 总完成率 < 门槛(0.6) ? 0 : 工资 × 0.1 × min(总完成率, 1)
```

- 只结算了周六或周日时，那天自成一组，公式不变。
- 只有工作日或只有双休有日回顾时，总完成率取有数据的那一侧，不把空窗期按 0 平均（否则半个月没结算会把完成率腰斩）。
- 当月任一天 `penalty_applied` → 金额 ÷ 3（只扣一次）。
- 工资是配置项（`salary`），不写死在 skill 里；为 0 时只显示公式和完成率。

## 10. 公式汇总

```
任务分   = 标题 $N（AI 预填 = 优先级底分 × 规模系数，用 `score --size S|M|L` 算）
结算分   = 任务分 × (主观超时 ? 0.5 : 1)        // 突破类不打折
日收入   = Σ 结算分 + Σ 习惯分
日分母   = min(60, max(30, Σ 当日计划任务有效分))
日完成率 = min(1, 日收入 / 日分母)
次日可花分钟 = max(0, min(日收入, 60) − 预留) × 2
周可花分钟   = min(Σ 本周得分, 360) × 1
月完成率 = 工作日/双休都有数据 ? avg(两者) : 有数据的一侧
月金额   = 月完成率 < 0.6 ? 0 : 工资 × 0.1 × 月完成率
```
