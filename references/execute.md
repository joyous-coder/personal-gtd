# 执行

理论：`时间管理.md` 的「执行」分支；`休息时长`、`做事有秩序`、`环境有条理`、`能力和条件`、`考虑变更方法` 等子笔记。

## 开始前 30 秒（只做三件，不重读整份计划）

1. 读 if-then 触发语；
2. 确认最低目标；
3. 准备物品 / 联系人。

## 计时

- 用户在滴答 App 手动开番茄或正计时；**AI 不起计时器、不催、不代打**。
- AI 只在结算时读 `focus` 记录（`focus list` 只读）。
- 积分不在执行时手算，结算时统一算（见 `scoring.md`）。

## 干扰

- 任务打标签 `内在干扰` / `外在干扰`；
- 用 `content` 或 `desc` 一句话记原因（0.1.8 没有 `task comment`）；
- 计划外的事补成 `U事件` 任务；
- 多个干扰合并到一个番茄处理；重要的下个番茄处理，不重要的往后推。

## 时刻了解（检查点问四件事）

1. 预估 / 已过 / 现在时间；
2. 正在做与接下来；
3. 目的、进度、资源；
4. 精力水平。

## 卡住诊断树

1. **先判「该不该继续」**：应不应该、能不能够、值不值得（回到筛选三问）。
2. 决定继续 → 依次排查：
   - **计划缺陷**：目的 / 工序 / 步骤 / 资源 / 技巧；
   - **自身局限**：身体 / 注意力 / 欲望 / 情绪 / 性格能力；
   - **环境阻力**：条件 / 凌乱 / 干扰 / 人的阻力。
3. **输出固定为三件**：一个诊断 + 一个最小动作 + 一个复查时间。不要一次给一堆建议。

## 收尾

结果确认 → 善后 → 结束计时 → 点击完成。积分留到结算时算，执行阶段不记分、不改标题。

## 语气

只针对机制，不评价人；给一个可立刻做的最小动作，而不是长篇分析。
